# Product Brief

## Company

turnturn is a coding assistant for software teams and builders. The product should help users understand codebases, plan changes, edit files, run checks, and explain tradeoffs clearly.

## Initial User

Early users are engineers working in active repositories who want a collaborative coding partner that is fast, trustworthy, and easy to supervise.

## Product Principles

- Make the user feel in control.
- Prefer transparent plans and verifiable actions.
- Read the codebase before changing it.
- Keep changes scoped and reversible.
- Treat tests, diffs, and command output as first-class conversation context.

## First Product Slice Options

- Local repo chat: ask questions over a codebase.
- Agentic edit loop: plan, patch, test, summarize.
- Review assistant: inspect diffs and flag risks.
- Setup assistant: bootstrap new developer machines and projects.
